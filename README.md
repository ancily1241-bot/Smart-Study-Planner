Smart Study Planner
Description
Smart Study Planner is a Python application that helps students manage study tasks and track academic progress.

Features
Add tasks
View tasks
Search tasks
Delete tasks
Save tasks
Load tasks
Files
core.py - Core functionality
text_app.py - Command-line version
gui_app.py - GUI version
tasks.json - Stores task data
Requirements
Python 3.x
Run the Text Version
python text_app.py

Run the GUI Version
python gui_app.py
